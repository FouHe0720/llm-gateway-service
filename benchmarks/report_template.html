如何读这份结果

测试范围
  • Mock 只衡量网关与调用策略。真实模型的准确率、生成速度和显存来自 Ollama 实验。
  • 冷启动表示服务进程或模型未驻留，未清空操作系统页缓存。TTFT 从请求开始计至首个非空文本块。
  • 准确率按固定答案严格匹配，失败也计入分母。重复测试同一道题，并不会增加独立题目数。
  • 生成 tokens/s 使用 Ollama 的生成 token 数与生成耗时，不包含排队、加载和 Prompt 处理。
  • 单机闭环压测和小样本结果不能外推为生产容量。客户端并发 2、模型端并行 1 时，延迟主要体现排队。
